# herdr-crew

The language used to describe a crew and its responsibilities. Project configuration terms describe the agreed simplification direction; rank and persona terms describe the current model until their replacement is settled.

## Language

**Baseline**:
The starting crew configuration and agent definitions installed into a project for its users to customize.

**Root configuration**:
The installed skill's shared baseline, from which projects receive their starting configuration and explicit upgrades.

**Project configuration**:
The crew configuration and agent definitions owned by one target project after baseline installation.

**Agent specification**:
The project-specific definition of an agent and its configuration, maintained through guided setup or direct customization.

**Agent guidance**:
The responsibilities, working rules and reporting expectations that an agent follows, distinct from the permissions its runtime enforces.

**Persona**:
Behavioral guidance describing an agent's responsibilities and approach to its work.

**Crew**:
A group of agents coordinating work on a shared task board.

**Rank**:
An agent's authority and permission boundary, separate from the work it performs.

**Permission profile**:
One of the existing Lead, Manager, Member or Inspector authority boundaries selected by an agent specification.

**Job persona**:
An agent's responsibility within a team, associated with a particular rank.

**Domain persona**:
Expertise that can be combined with a job persona without changing its authority.

**Team**:
A group of agents assigned to a particular task.

**Handoff**:
A saved account of progress, evidence, and remaining work that lets a replacement agent continue.
